# 코스 소개 — 대화형 AI 사용하기

> 이 문서는 `/olive/experience`와 `/olive/experience/1`부터 `/6`까지 **현재 화면에 표시되는 콘텐츠**를 순서대로 정리한 원고입니다. 인터랙션과 퀴즈는 작동 방식과 화면 문구를 코드 블록으로 기록했습니다.

AI가 무엇인지 알아보고, 직접 대화하고 답을 다듬으며 내 일에 쓰는 방법을 익혀 봅니다.

```text
코스 시작 영역
- 제목: 첫 대화부터 시작해볼까요?
- 난이도: 입문
- 소요 시간: 약 1시간 · 6단계
- 완주자: 0명
- 공유: 링크 복사, X, LinkedIn, Facebook
- 버튼: 코스 시작하기 → /olive/experience/1
```

## 어떤 코스인가요?

AI에게 요청하고, 답을 받아 보고, 원하는 대로 고쳐 보는 입문 코스입니다. AI와 대화형 AI서비스가 무엇인지부터 가볍게 살펴보고, 대부분의 시간은 직접 해 보는 데 씁니다. 약 1시간이면 마칠 수 있어요.

## 누구를 위한 코스인가요?

AI를 거의 써 보지 않았거나, 내 일에 어떻게 적용할지 감이 오지 않는 분을 위한 코스입니다.

## 무엇이 필요한가요?

- ChatGPT나 Claude 계정
- 평소에 고민하는 실제 업무 한 가지

## 코스를 마치면 무엇이 남나요?

- AI가 무엇이고 대화형 AI서비스와 어떤 관계인지에 대한 기초 이해
- 프롬프트를 쓰고, 맥락을 주고, 답을 검토하는 더 탄탄한 습관
- 평소 자주 하는 실제 업무 하나를 더 낫게 다듬은 결과물

## 코스 목차

각 단계를 마치면 다음 단계가 열립니다.

1. 시작하기 · 3분 — 이 코스에서 어떤 일을 해 볼지 살펴봅니다.
2. AI란 무엇일까요? · 7분 — AI와 LLM은 어떻게 다르고, 대화형 AI서비스는 이를 어떻게 활용하는지 알아봅니다.
3. 첫 대화 해보기 · 10분 — AI 서비스 하나를 골라 예시 요청을 보내고, 첫 답변을 받아 봅니다.
4. 요청 다듬기 · 15분 — 저녁 메뉴를 요청하면서 필요한 정보를 더하고, 답변을 본 뒤 후속 요청으로 다듬어 봅니다.
5. 내 일에 써 보기 · 15분 — 메일 초안, 긴 글 요약처럼 내 일에 맞는 요청을 직접 만들어 보냅니다.
6. 돌아보고 이어가기 · 7분 — 답을 확인하는 기준을 익히고, AI를 계속 배워 갈 방법을 살펴봅니다.

```text
단계 화면의 공통 동작
- 상단에는 ‘← 코스 소개’, 현재 단계 / 전체 6단계와 ‘목차 보기’ 버튼이 표시됩니다. 단계 제목과 소개 문구는 화면에 표시하지 않습니다.
- ‘목차 보기’를 누르면 본문 위에 뜨는 한 줄짜리 세로 목록으로 여섯 단계가 표시되고, ‘목차 닫기’를 누르면 다시 숨겨집니다. 이전·다음 단계 링크로도 이동할 수 있습니다.
- 코스 소개와 단계 목차에서는 완료한 단계와 현재 열린 단계에만 접근할 수 있습니다. 잠긴 단계의 주소를 직접 열면 현재 진행할 수 있는 첫 단계로 이동합니다.
- 2·4단계는 퀴즈 정답 확인 후, 3·5단계는 확인 항목을 모두 체크한 후 다음 단계가 열립니다. 1단계는 열어 보면 다음 단계가 열립니다.
- 퀴즈는 답을 선택한 뒤 ‘정답 확인하기’를 누릅니다. 정답이면 “맞아요.”와 해설을, 오답이면 “다시 생각해 보세요. 힌트:”와 힌트를 보여 줍니다.
- 확인 항목은 체크박스로 표시되며, 선택 상태는 같은 탭에서 단계를 이동하거나 새로고침해도 유지됩니다.
- 요청 입력창은 선택한 서비스에 맞춰 ‘ChatGPT로 보내기’ 또는 ‘Claude로 보내기’를 표시합니다. 버튼은 요청을 담은 새 탭을 열고, “작성한 요청을 담아 새 탭을 엽니다. [서비스 이름]에서 내용을 확인하고 전송해 주세요.”라고 안내합니다.
- 코스 소개의 링크 복사가 성공하면 “링크를 복사했어요.”, 실패하면 “복사하지 못했어요. 주소창의 링크를 복사해 주세요.”라고 표시합니다.
```

# 1. 시작하기

> 이 코스에서 어떤 일을 해 볼지 살펴봅니다.

```text
영상 자리 표시
- 제목: 이 코스에서 함께 해 볼 것
- 설명: AI에 대한 간단한 지식과 해당 코스를 통해서 작업할 간단한 내용, 예시 내용 등..
```

## 대화형 AI 사용하기 코스에 오신걸 환영합니다

여러분은 이 코스에서 AI에 대한 간단한 지식을 익히고, 실제 업무 하나를 AI와 함께 해결해 보게 됩니다.

읽기만 하는 코스가 아닙니다. 한 시간 동안 코스 곳곳에서 여러 활동들을 진행하게 됩니다.

```text
코스 활동 소개
- 퀴즈 풀기: 배운 내용을 짧은 퀴즈로 확인하고, 틀리면 힌트를 보고 다시 풀어 봅니다.
- 직접 요청하기: 예시 요청부터 내 고민까지, ChatGPT나 Claude에 질문하고 직접 답을 받아 봅니다.
- 검토하기: 원하는 요구사항을 잘 수행했는지 확인하고 필요하다면 수정해서 다시 요청해봅니다.
- 확인해보기: 코스를 마친 후 목표를 이루었는지 확인해봅니다.
```

## 시작하기 전에 알아 두세요

- 3단계부터 ChatGPT나 Claude에 실제로 요청을 보냅니다. 새 탭에 미리 열어 두면 편해요.
- 정답은 없어요. AI의 답이 예시와 달라도, 중간에 막혀도 괜찮습니다.

자, 준비가 되었다면 다음 단계에서 AI가 무엇이고 대화형 AI와 어떻게 대화할 수 있는지 가볍게 살펴봅니다.

# 2. AI란 무엇일까요?

> AI와 LLM은 어떻게 다르고, 대화형 AI서비스는 이를 어떻게 활용하는지 알아봅니다.

**AI(인공지능)**는 컴퓨터가 사람처럼 보고, 듣고, 말하거나 판단하도록 만드는 기술을 두루 가리키는 가장 큰 범위의 말이에요. 영상 추천, 얼굴 인식, 길 찾기, 자동 번역처럼 서로 다른 일을 하는 기술이 모두 AI에 포함됩니다.

**LLM(대규모 언어 모델)**은 그중에서 글과 대화를 다루도록 만들어진 AI 모델의 한 종류예요. 아주 많은 글을 미리 살펴보며 단어와 문장이 어떤 관계로 쓰이는지 학습합니다. 그래서 질문에 답하거나, 글을 요약하거나, 초안을 만드는 일을 할 수 있어요.

**ChatGPT** 혹은 **Claude** 등의 대화형 AI들은 LLM을 바탕으로 만든 AI 서비스예요. 우리가 대화창에 요청을 입력하면 LLM이 글을 만들고, AI서비스가 그 결과를 화면에 보여 줍니다. LLM이 글을 다루는 ‘엔진’이라면, ChatGPT나 Claude는 그 엔진을 우리가 편하게 사용할 수 있도록 만든 ‘서비스’라고 보면 되요.

```text
포함 관계 그림
AI — 가장 큰 범위
  보고, 듣고, 말하고, 판단하는 여러 기술
  └─ LLM — AI의 한 종류
       글과 대화를 이해하고 만드는 언어 모델
       └─ ChatGPT, Claude, Gemini... — LLM을 활용한 대화형 AI 서비스
            LLM과 여러 기능을 대화로 편리하게 사용할 수 있게 만든 서비스
```

## 대화형 AI 서비스에 질문하면 어떤 일이 일어날까요?

질문을 입력하면 모델이 답변 전체를 한꺼번에 만드는 것은 아닙니다. 다음에 올 가능성이 높은 단어나 구절을 예측하며 한 단계씩 답변을 완성합니다.

```text
인터랙션: 모델이 답변을 만드는 단계
- 입력 / 모델의 예측 / 출력 카드를 클릭하면 해당 설명과 예시가 바뀝니다.

1. 입력 — 질문과 대화 내용을 일기
   설명: 사용자가 보낸 질문과 앞서 나눈 대화가 모델이 참고하는 맥락이 됩니다.
   사용자의 질문: “비가 오는 날 외출할 때 무엇을 챙기면 좋을까?”
   모델이 참고하는 맥락: 사용자의 질문 + 앞서 나눈 대화

2. 모델의 예측 — 다음에 올 말의 후보를 예측
   설명: 모델은 학습한 언어의 패턴과 현재 맥락을 바탕으로 다음에 이어질 가능성이 높은 말의 조각을 고릅니다.
   예시: 비가 오는 날 외출할 때 무엇을 챙기면 좋을까? →
   다음 말의 후보: 우산을 72%, 비옷을 18%, 장화를 10%

3. 출력 — 고른 말을 더하고 다시 예측
   설명: 새로 만든 말은 다음 예측의 맥락에 포함됩니다. 이 과정을 여러 번 반복해 하나의 답변을 완성합니다.
   반복해서 만들어진 답변: “우산을 챙기면 좋아요.”
   흐름: 예측 → 출력에 추가 → 새 맥락으로 다시 예측
```

새로 만들어진 단어는 다음 단어를 예측할 때 참고하는 맥락에 포함됩니다. 이렇게 작은 단계를 여러 번 반복하면서 하나의 완성된 답변을 만듭니다. 이 과정은 검색이 아니라 예측이라고 설명할 수 있습니다. 모델이 데이터베이스에 저장된 답변을 그대로 꺼내는 것이 아니라, 학습한 패턴과 사용자의 지시, 대화의 맥락을 바탕으로 새로운 답변을 생성하기 때문입니다.

다음 단계에서는 직접 AI 서비스를 열어 첫 대화를 나눠 봅니다.

## 퀴즈로 확인하기

```text
질문: ChatGPT에 대한 설명으로 가장 알맞은 것은 무엇인가요?
1. 모든 질문의 정답을 보장하는 사전이다.
2. LLM을 바탕으로 요청에 맞는 답을 만들어 주는 AI 서비스다. [정답]
3. 내 질문을 받은 사람이 대신 답을 써 주는 서비스다.

오답 힌트: ChatGPT의 대화창 뒤에서 답변을 만드는 역할을 누가 맡는지 떠올려 보세요.
정답 해설: ChatGPT는 대규모 언어 모델(LLM)을 바탕으로 만든 AI 서비스예요. 모델은 미리 학습한 내용과 우리가 보낸 요청을 보고 답을 만들지만, 그 답이 맞는지는 내가 확인해야 해요.

동작: 답을 고른 뒤 ‘정답 확인하기’를 누릅니다. 정답은 초록색, 오답은 빨간색으로 표시됩니다. 선택을 바꾸면 다시 확인할 수 있습니다.
```

더 알고 싶다면: [OpenAI의 ChatGPT 사용 안내](https://learn.chatgpt.com/docs/use-chatgpt)

# 3. 첫 대화 해보기

> AI 서비스 하나를 골라 예시 요청을 보내고, 첫 답변을 받아 봅니다.

```text
서비스 선택
- 안내: 선호하는 서비스를 선택해 주세요.
- ChatGPT (OpenAI) / Claude (Anthropic) 중 하나를 고릅니다.
- 기본 선택: ChatGPT
- 선택 후 안내: 이후 요청은 선택한 서비스로 보냅니다.
```

둘 다 평소 말하듯 요청하면 됩니다. 처음에는 편한 서비스 하나면 충분해요. 다른 AI 서비스나 기능은 써 보다가 필요해질 때 하나씩 알아가도 늦지 않습니다.

## 첫 대화를 보내 보세요

예시를 그대로 보내도 되고, 조금 바꿔도 좋아요. 입력창 아래의 보내기 버튼을 누르면 선택한 서비스의 새 탭에 요청을 담아 엽니다.

```text
나의 첫 대화 — 편집 가능한 요청
나는 대화형 AI를 처음 써봐.
일상에서 해볼 만한 간단한 활용 예시를 세 가지 알려줘.
각 예시마다 내가 그대로 입력할 수 있는 요청 문장도 써줘.

동작: 선택한 ChatGPT 또는 Claude의 새 탭에 작성한 요청을 담아 엽니다. 그곳에서 내용을 확인하고 전송합니다.
```

로그인 화면이 나타나면 로그인해 주세요. 요청이 입력되지 않았다면 로그인 후 이 페이지에서 전송 버튼을 다시 눌러 보세요.

```text
확인 항목
[ ] AI에게서 첫 답변을 받았어요.
```

## 이제 원하는 것을 물어볼 차례예요

첫 질문을 보내고 답변까지 받아 보았어요. 이제 예시를 따라 하는 데서 한 걸음 더 나아가, 내가 실제로 궁금한 것이나 도움받고 싶은 일을 AI에게 물어볼 차례입니다. 예를 들어볼까요?

> 간단한 저녁 메뉴를 추천해 줘.

위처럼 거창한 질문일 필요는 없어요. 오늘 먹을 메뉴, 읽고 있는 글에서 이해되지 않는 부분, 작성하기 어려운 문장처럼 지금 나에게 필요한 것부터 편하게 물어보세요.

다음 단계에서는 원하는 답변에 더 가까워질 수 있도록 요청에 필요한 정보를 더하고, 받은 답변을 다시 다듬는 방법을 자세히 알아봅니다. 직접 요청을 작성하고 결과가 어떻게 달라지는지도 확인해 볼 거예요.

더 알고 싶다면: [OpenAI의 프롬프팅 안내](https://learn.chatgpt.com/docs/prompting), [ChatGPT](https://learn.chatgpt.com/docs), [Gemini](https://support.google.com/gemini/answer/17216260?hl=en), [Claude Academy](https://academy.claude.com/)

# 4. 요청 다듬기

> 저녁 메뉴를 요청하면서 필요한 정보를 더하고, 답변을 본 뒤 후속 요청으로 다듬어 봅니다.

## 오늘 저녁 메뉴를 결정해 봅시다

“간단한 저녁 메뉴를 추천해 줘.”라고 물어도 AI는 답할 수 있어요. 하지만 내 취향이나 상황을 모르면 지금 나에게 잘 맞는 메뉴를 고르기는 어렵습니다. 원하는 답변에 영향을 주는 정보를 함께 알려주면 추천을 실제 선택에 쓰기 쉬워져요.

이렇게 대화형 AI서비스에 무엇을 알고 싶고, 만들고 싶고, 바꾸고 싶은지 알려주는 방법을 프롬프팅이라고 합니다. 프롬프트는 질문일 수도, 지시일 수도, 목표일 수도 있습니다. 특별한 명령어나 정해진 공식은 필요하지 않습니다. 평소 쓰는 말로 시작해 답변을 확인하고, 후속 메시지로 결과를 다듬어 볼수도 있어요.

짧은 프롬프트만으로 충분할 때도 많지만 더 나에게 맞는 결과물을 얻기위해 여러가지 정보를 추가할 수 있습니다.

- 목표: 무엇을 해야 하나요?
- 맥락: 어떤 정보나 자료가 도움이 되나요?
- 결과물: 어떤 형식과 길이로, 얼마나 자세히 받고 싶나요?
- 제약 조건: 무엇을 바꾸면 안 되나요? 무엇을 피하거나 실행 전에 확인해야 하나요?

아래에서 간단한 저녁메뉴를 추천받기 위한 여러가지 정보를 추가하고 대화형 AI에게 전달해봅시다.

```text
저녁 메뉴 요청 만들기
고정 목표: 오늘 먹을 저녁 메뉴 정하기

맥락 — 직접 입력
  입력 예시: 매콤한 한식을 좋아하고, 냉장고에 두부와 달걀이 있어요.
결과물 — 직접 입력
  입력 예시: 메뉴 세 가지를 재료와 조리 시간까지 비교해 주세요.
제약 조건 — 직접 입력
  입력 예시: 1인분 기준 30분 안에, 재료비 10,000원 이내로 만들 수 있어야 해요.

완성된 요청의 시작: 오늘 먹을 저녁 메뉴를 정하고 싶어요.
완성 방식: 각 입력값을 맥락 → 결과물 → 제약 조건 순서로 이어 붙이고, 문장 끝에 문장 부호가 없으면 마침표를 붙입니다. 빈칸은 건너뜁니다.

위 예시를 모두 입력했을 때:
오늘 먹을 저녁 메뉴를 정하고 싶어요. 매콤한 한식을 좋아하고, 냉장고에 두부와 달걀이 있어요. 메뉴 세 가지를 재료와 조리 시간까지 비교해 주세요. 1인분 기준 30분 안에, 재료비 10,000원 이내로 만들 수 있어야 해요.

동작: 완성된 요청은 읽기 전용 입력창에 바로 표시됩니다. 버튼을 누르면 선택한 서비스의 새 탭에 요청을 담아 엽니다.
```

모든 칸을 채우지 않아도 됩니다. 먼저 기본 요청을 보내 보고, 필요한 정보를 하나씩 더해 답변이 어떻게 달라지는지 살펴보세요.

## 요청을 다듬어봅시다.

첫 요청이 완벽할 필요는 없어요. 받은 추천을 살펴본 뒤, 빠진 정보를 더하거나 한눈에 볼 수 있도록 정리해달라고 한다거나, 달라진 상황과 원하는 수정 방향을 같은 대화창에서 말하면 답변을 수정할 수 있습니다. 메세지를 보냈던 창으로 이동해서 후속 요청을 보내보세요.

```text
인터랙션: 후속 요청에 따른 답변 변화
아래 답변은 학습을 위해 미리 작성한 예시입니다. 실제 AI가 생성한 결과와는 다른 내용이에요.

처음 받은 답변 예시:
가장 추천하는 메뉴는 닭가슴살 순두부찌개예요. 한식이면서 조금 매콤하게 만들 수 있고, 닭가슴살과 순두부를 함께 넣으면 단백질을 챙기기 좋아요. 약 25분 안에 만들 수 있습니다.

처음에는 “어떻게 바꾸고 싶나요? 위에서 요청을 고르면 수정된 예시가 나타납니다.”가 표시됩니다.

[재료 바꾸기]를 선택하면
후속 요청: 닭가슴살은 없고 두부와 달걀이 있어. 이 재료를 쓰는 메뉴로 다시 추천해줘.
수정된 답변: 두부 달걀 덮밥을 추천해요. 두부를 노릇하게 굽고 달걀을 곁들여 밥 위에 올리면 약 25분 안에 만들 수 있어요. 단백질 30g을 맞추려면 두부 한 모와 달걀 두 개를 사용하고, 제품의 영양 정보를 함께 확인해 주세요.

[조건 더하기]를 선택하면
후속 요청: 오늘은 속이 불편해서 맵지 않고 기름기가 적은 한식으로만 다시 골라줘.
수정된 답변: 오늘은 맵지 않은 닭고기 채소죽을 가장 추천해요. 닭가슴살과 달걀을 넣으면 담백하면서도 단백질을 보충할 수 있고, 기름을 거의 쓰지 않아 부담이 적어요. 약 30분 정도 걸리며 예상 단백질 양은 재료의 제품 표시를 확인해 조절해 주세요.

[비교하기 쉽게]를 선택하면
후속 요청: 메뉴 이름, 예상 조리 시간, 예상 단백질 양, 추천 이유를 표로 정리해줘.
수정된 답변:
메뉴 | 조리 시간 | 예상 단백질 | 추천 이유
닭가슴살 순두부찌개 | 약 25분 | 약 35g | 한식이고 단백질을 챙기기 쉬움
소고기 청경채 볶음 | 약 20분 | 약 30g | 빠르게 만들 수 있는 중식 스타일
두부 달걀 덮밥 | 약 25분 | 약 30g | 재료가 단순하고 든든함
단백질 양은 사용한 재료와 양에 따라 달라질 수 있어요.
```

후속 요청은 길게 쓰지 않아도 됩니다. 바꾸고 싶은 점 한두 가지만 분명히 말하면 충분해요. 예를 들어 봅시다.

- **바꿀 것과 그대로 둘 것을 함께** — “첫 번째 메뉴는 그대로 두고, 나머지 두 개만 더 간단한 것으로 바꿔줘.”
- **빠뜨린 정보 더하기** — “냉장고에 돼지고기가 있어. 그걸 쓰는 메뉴로 다시 추천해줘.”
- **자세함의 정도 조절** — “조리 순서는 빼고 재료와 예상 시간만 알려줘.”
- **다른 선택지 보기** — “맵지않은 다른 메뉴 세 가지도 보여줘.”
- **꼭 지킬 조건 알려주기** — “예산은 그대로 유지해줘. 매운 음식은 빼줘.”
- **쓰기 좋은 형태로 받기** — “표 형식으로 정리해줘.”

답변을 중요한 일에 쓸 때는 마지막에 점검을 부탁해도 좋아요. “빠진 재료가 없는지 확인해줘”처럼 말하면 AI가 한 번 더 살펴봅니다. 물론 최종 확인은 내가 해야 합니다.

한 번에 모든 것을 고치려 하지 않아도 괜찮아요. 요청하고, 답변을 보고, 다시 요청하는 과정을 두세 번 거치는 편이 처음부터 완벽한 요청을 쓰는 것보다 쉽고 빠를 때가 많습니다.

## 퀴즈로 확인하기

```text
상황: 친구에게 보낼 생일 축하 메시지가 필요해 AI에 “생일 축하 메시지 써줘.”라고 요청했습니다.
AI의 답변(교육용 예시): 생일 진심으로 축하해! 🎂🎉 오늘은 맛있는 것도 많이 먹고, 행복한 일만 가득한 하루 보내길 바라!
친구에게 보낼 메시지로는 너무 간단하고 평범하게 느껴집니다. 친구와 평소 대화하듯 편하고 장난기 있는 메시지로 바꾸려면, 어떤 후속 요청이 가장 도움이 될까요?

질문: 친구에게 보낼 메시지를 원하는 말투로 바꾸려면 어떤 후속 요청이 가장 도움이 될까요?
1. “너무 평범해. 이번에는 더 잘 써줘.”
2. “10년지기 친구에게 카톡으로 보낼거야. 반말로, 가볍게 장난치는 말투로 두세 문장가량 작성해줘.” [정답]
3. “마음에 들지 않아. 다시 만들어줘.”

오답 힌트: 처음 요청에는 받는 사람과 원하는 말투에 대한 정보가 없습니다. 이 정보를 알려주는 선택지를 찾아보세요.
정답 해설: 받는 사람과 메시지를 보낼 곳, 원하는 말투와 길이를 구체적으로 알려주면 AI가 그 정보를 참고해 답변을 바꿀 수 있습니다. “더 잘 써줘”라고 하거나 같은 요청을 반복하면 원하는 방향을 충분히 전달하기 어렵습니다.
```

# 5. 내 일에 써 보기

> 메일 초안, 긴 글 요약처럼 내 일에 맞는 요청을 직접 만들어 보냅니다.

저녁 메뉴를 정하면서 요청을 만들고 다듬어 봤습니다. 이렇게 요청을 만들고 다듬은 방법 그대로 다른일도 요청해볼 수 있어요. 앞에서 쓴 목표와 맥락, 결과물, 제약 조건을 그대로 옮기면 됩니다.

```text
예시 카드: 메일 초안 쓰기
목표: 다음 주 회의 일정을 조율하는 메일을 써줘.
맥락: 동료 두 명에게 보내고, 화요일 오전 10시와 목요일 오후 2시가 가능해.
결과물: 제목과 본문을 나눠 정중하지만 간결하게 써줘.
제약 조건: 날짜와 시간은 바꾸지 말고, 내가 확인할 수 있게 초안으로만 써줘.

예시 카드: 긴 글 요약하기
목표: 해리포터 소설을 요약해줘.
맥락: 어린 아이를 재울 때 읽어줄 예정이야.
결과물: 중요한 이벤트는 잊지말고, 어린 아이도 이해할 수 있는 내용으로 작성해줘.
제약 조건: 소설에 없는 내용은 넣지 말고, 빠진 정보가 있으면 알려줘.

예시 카드: 용어 설명 듣기
목표: ROAS가 무엇인지 설명해줘.
맥락: 나는 마케팅 업무를 이번에 처음 맡았어. 숫자에 익숙하지 않아.
결과물: 쉬운 말로 설명하고, 예시를 하나 들어줘.
제약 조건: 어려운 용어를 쓸 때는 바로 뜻을 풀어서 써줘.
```

세 예시 모두 ‘목표 → 맥락 → 결과물 → 제약 조건’ 순서로 이어져 있어요. 네 가지를 매번 다 채워야 하는 것은 아니고, 도움이 될 것만 골라 담으면 됩니다.

프롬프트에 정해진 문법이나 양식은 없습니다. 질문이어도 되고, 하고 싶은 일을 그대로 적어도 돼요. 짧은 한 줄로 충분한 날도 많고, 결과가 중요한 일일수록 네 가지를 챙기면 받는 답이 달라집니다.

## 이번에는 내 일로 만들어 봅시다

요즘 하는 일이나 미뤄 두었던 일에서 하나를 골라 보세요. 칸을 채우면 보낼 요청이 완성되고, 앞에서 고른 서비스로 바로 보낼 수 있어요. 떠오르지 않으면 예시를 열어 가져다 쓰면 됩니다.

```text
내 요청 만들기
- ‘막히면 예시 보기’를 누르면 메일 초안 / 긴 글 요약 / 용어 설명 예시 버튼이 나타납니다.
- 예시 버튼을 누르면 해당 예시의 네 항목이 입력칸에 채워집니다.

목표 — 예: 다음 주 회의 일정을 조율하는 메일을 써줘.
맥락 — 예: 동료 두 명에게 보내고, 화요일 오전과 목요일 오후가 가능해.
결과물 — 예: 제목과 본문을 나눠 정중하지만 간결하게 써줘.
제약 조건 — 예: 날짜는 바꾸지 말고, 보내기 전에 확인할 수 있게 초안으로만.

완성 방식: 목표 → 맥락 → 결과물 → 제약 조건 순서로 문장을 이어 붙입니다. 빈칸은 건너뛰고, 문장 끝에 문장 부호가 없으면 마침표를 붙입니다.
전송 조건: 목표를 적으면 버튼이 활성화됩니다. 맥락·결과물·제약 조건은 선택 입력입니다.
동작: 선택한 서비스의 새 탭에 완성된 요청을 담아 엽니다.
```

입력한 내용은 ‘목표 → 맥락 → 결과물 → 제약 조건’ 순서로 이어집니다. 목표만 적어도 보낼 수 있고, 아래 칸을 더할수록 요청이 또렷해져요.

## 보내기 전에 확인해 보세요

```text
확인 항목
[ ] 무엇을 해달라는 요청인지 알아볼 수 있다.
[ ] AI가 모를 상황과 자료를 담았다.
[ ] 원하는 결과의 형태나 길이를 알려 줬다.
[ ] 바꾸면 안 되는 것이나 피해야 할 것을 적었다.
```

## 오늘 해 본 것

한 번 해 봤다고 바로 익숙해지지는 않아요. 그래도 요청하고, 답변을 보고, 다시 요청하는 일을 반복하다 보면 어떤 정보를 미리 알려주면 좋은지 감이 생깁니다. 그 감각이 쌓인 것이 프롬프팅 실력이에요.

잘 통한 요청은 메모해 두고 다음에 다시 써 보세요. 그렇게 모인 문장들이 나만의 방식이 됩니다. 마지막 단계에서는 받은 답변을 그대로 써도 될지 판단하는 기준과, 앞으로 AI를 배워 갈 방법을 함께 정리합니다.

# 6. 돌아보고 이어가기

> 답을 확인하는 기준을 익히고, AI를 계속 배워 갈 방법을 살펴봅니다.

## 답을 그대로 사용하기 전에

AI는 자연스럽고 자신 있게 말하지만, 내용이 항상 맞지는 않아요. 내가 알려주지 않은 사정이 빠져 있을 수도 있고, AI가 잘못 이해한 부분이 있을 수도 있어요. 답변을 곧이곧대로 믿기 전에 세 가지만 확인해 보세요.

```text
확인 기준
- 사실과 숫자가 원래 자료와 같은가요?
- 내가 요청한 조건이 빠짐없이 담겼나요?
- 내 상황에서 실제로 쓸 수 있는 결과인가요?
```

확인을 마쳤다면 마지막 판단은 내 몫입니다. AI는 초안을 빠르게 만들어 주지만, 무엇이 사실이고 지금 상황에 맞는지, 그대로 내보낼 준비가 되었는지는 내가 정해야해요. 보고서에 담기거나 동료에게 전해지는 순간 그것은 AI가 아니라 내 이름으로 나가는 결과물이기 때문입니다.

그래서 돈이나 건강, 계약처럼 결과가 큰 일은 AI의 답을 참고 자료로만 쓰고, 담당자나 전문가에게 한 번 더 확인하는 편이 좋습니다. AI는 판단을 돕는 도구이지, 판단을 대신하는 도구가 아니라는것을 인지해둡시다.

## AI는 이렇게 계속 배워 가요

한 번에 익히겠다는 생각보다 자주 써 보면서 손에 익히는 도구라고 생각해야 합니다. 오늘부터 이렇게 시작해 보세요.

- 하루에 한 번, 작은 일 하나를 AI에게 먼저 맡겨 보기
- 답이 잘 나온 요청은 모아 두고 다음에 다시 쓰기
- 마음에 안 들면 포기하지 말고 한 번 더 요청해 보기
- 써 본 경험을 사람들과 나누고, 서로의 방법 배우기

```text
영상 자리 표시
- 제목: 앞으로 AI를 어떻게 배워 나갈지
- 설명: 오늘 해 본 것을 돌아보고, 내 일에 AI를 더 넓게 쓰기 위해 어떻게 배워 나가면 좋을지 소개하는 마무리 영상
```

문의하기

Agent 개발방법을 배우고, 실무에 적용하는
LC - Learning Consulting

만들어도, 배워도 AI는 막상 실무에서 멈추기 쉽습니다.
LC - Learning Consulting 은 개발 방식과 학습 방식을 함께 설계해 그 간극을 좁힙니다.

도입 문의

왜 LC - Learning Consulting일까요?

Agent, 데모는 되지만 실무에선 깨집니다.
배워도, 실무로 이어지지 않습니다.
LC - Learning Consulting은 콘텐츠와 방식, 두 축을 함께 다루며 실무에서 작동하는 AI 활용 역량을 만듭니다.

  • Agent 개발의 문제

    데모는 만들지만 실무 환경에서는 쉽게 깨집니다.

    실용적인 개발 방식, 하네스, 검증 콘텐츠로 해결합니다.

  • 학습의 문제

    배웠다는 감각은 있지만 실제 업무 흐름으로 이어지지 않습니다.

    협력, 실전 적용, 피드백이 있는 학습 방식으로 해결합니다.

LC - Learning Consulting은
학습에서 끝내지 않습니다.

강의로 끝나는 교육이 아니라, 본인의 현업 과제로 한 사이클을 완주합니다.

  1. 오프라인 · Day 1 - 2

    학습

    Agent의 원리와 실전 개발 흐름을 익힙니다.

  2. 온라인 · 2주

    적용

    본인의 현업 과제에 적용하고
    매주 피드백을 받습니다.

  3. 오프라인 · Day 3

    개선

    최종 피드백을 통해 워크플로우를 완성합니다.

역할에 맞는 과정,
목표에 맞는 구성

팀의 역할에 맞는 과정을 선택하고, 교육 목표에 맞춰 진행 구성을 결정합니다.

과정 안내

두 과정 모두 집중 학습 또는 실전 완주 구성으로 도입할 수 있습니다.

  • Agent Workflows
    for Builders
    대상
    디자인, 기획, PM, IT 관련자 등 비개발자
    해결 과제
    개발 의존으로 느린 검증, 데모에서 멈추는 결과물
    기대 효과
    기본 테스팅과 신뢰 경계를 갖춰, 본인 업무에 믿고 쓸 Agent를 직접 개발합니다.
  • Agent Workflows
    for Engineers
    대상
    주니어 수준 전문 개발자
    해결 과제
    임기응변식 프롬프트, 하네스와 패턴 선택 기준 부재
    기대 효과
    올바른 설계, 판단, 검증, 평가 기준을 세우고 상황별 최적 하네스 엔지니어링을 익힙니다.

구성 안내

구성에 따라 학습 이후 실무 적용과 개선까지 이어갈 수 있습니다.

집중 학습
2day

Day 1 - 2 동안 핵심 원리와 실전 개발 흐름을 집중적으로 학습합니다.

실전 완주
2day + 2주 실무 적용 + 3day

집중 학습 이후 현업 과제에 적용하고, 최종 개선까지 이어갑니다.

구성별 진행 범위

집중 학습

  • 학습 Day 1 - 2
  • 적용
  • 개선

실전 완주

  • 학습 Day 1 - 2
  • 적용 2주 · 온라인
  • 개선 Day 3

학습 커리큘럼

두 과정 모두 Day 1 원리, Day 2 실전 흐름으로 진행합니다.

  • Agent Workflows
    for Builders

    Day 1 · 원리

    • 프롬프트, 컨텍스트, 하네스의 개념과 차이
    • 개발 워크플로우와 Agent 개발 워크플로우의 차이
    • Agent가 잘하는 것과 못하는 것, 신뢰 경계
    • 비개발자에게 필요한 개발지식 에센셜

    Day 2 · 실전

    • Agent 개발 환경과 시스템, Claude Code와 Codex CLI
    • 실무 주제 페어 실습, 워크플로우 기반 Agent 설계와 제작
    • 신뢰성을 확보하는 기본 테스팅
    • 그룹 세션을 통한 진행 사항 공유

  • Agent Workflows
    for Engineers

    Day 1 · 원리

    • 아키텍처 설계, 리팩토링, 코드 평가의 엔지니어링 기본
    • 올바른 설계와 판단의 기준 세우기
    • 상황별 하네스 엔지니어링 전략

    Day 2 · 실전

    • 사례별 개발 워크플로우 패턴 실습
    • 실무 주제 페어 실습과 결과물 검증, 평가
    • 나의 워크플로우 개선점 도출과 전략 계획
    • 그룹 세션을 통한 진행 사항 공유

* 실전 완주 구성은 2주 실무 적용과 Day 3 개선까지 이어집니다. 자세한 커리큘럼은 도입 문의 시 제공합니다.

회사에 남는 것

  • 실전 완주

    결과물

    연습 과제가 아니라 실무에서 실제로 돌아가는 Agent를 남깁니다.

  • 실전 완주

    일반화 리포트

    참가자 사례를 모아 일반화한 리포트를 회사의 학습 자산으로 남깁니다.

  • 공통

    지속적인 업데이트 콘텐츠

    수료 후에도 접근할 수 있는 최신 학습 콘텐츠를 제공합니다.

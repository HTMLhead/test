# 코드스쿼드: Dala 레퍼런스 적용 방향

검토일: 2026-09-22
레퍼런스: https://dala.craftedbygc.com/
목표: Dala의 시각적 표현과 스크롤 연출을 참고해 코드스쿼드 AX 홈페이지 개편. 원본 서비스의 문구·인물·브랜드를 복제하지 않는다.

## 실제 화면에서 확인한 표현

- 검은 배경 위에 흰색의 큰 제목을 배치한다.
- 보라색의 둥근 버튼이 주 행동을 구분한다.
- 다색의 입자가 화면 전역에 분포하고, 스크롤 구간에서 구형의 집합으로 변화한다.
- 짧은 제목과 본문이 왼쪽·오른쪽·중앙으로 배치되며 이야기의 흐름을 만든다.
- 고정된 상단 탐색과 요청 버튼이 긴 페이지에서도 접근 경로를 유지한다.
- 모바일에서도 큰 제목과 전체 배경 효과를 사용한다. 코드스쿼드 적용 시에는 글 뒤의 입자 밀도를 줄이고 모션 정지 기능을 둔다.

캡처: desktop-start.png, desktop-12.png, desktop-26.png, desktop-42.png, desktop-58.png, desktop-75.png, desktop-92.png, mobile-start.png. 프레임은 애니메이션의 한 시점이다.

## 코드스쿼드의 이야기

주제: **혼자의 가능성이, 함께 만드는 변화로.**

첫 화면에서는 큰 문장과 입자 군집으로 ‘사람마다 다른 가능성’을 표현한다. 주 행동은 ‘AX 미션 시작하기’, 보조 행동은 ‘우리가 배우는 방식’이다.

| 장면 | 사용자에게 전달할 내용 | 시각적 변화의 제안 |
|---|---|---|
| 가능성 | AI를 알아가는 데서 실제로 활용하는 역량으로 | 서로 다른 점들이 느리게 움직인다 |
| 만들기 | 내 업무의 문제로 시작해 작게 만들어 본다 | 점들이 하나의 구체적인 구조로 모인다 |
| 함께 배우기 | 동료의 관점과 피드백으로 개선한다 | 여러 군집이 연결된다 |
| 직접 체험 | AI가 요약한 회의록을 검토한다 | 배경 밀도를 낮추고 미션에 집중한다 |
| 신뢰 | 국내 주요 기업과 쌓은 10년의 실전 교육 경험 | 단정한 기관명과 사실 중심의 정보 |
| 순환 | 자유와 책임, 존중과 포용, 배움과 공헌 | 연결이 열린 순환 형태로 확장된다 |
| 시작 | 나와 조직에 맞는 교육을 함께 논의한다 | 짧은 문의 경로로 마무리한다 |

## 표현 원칙

- 원본보다 본문 뒤의 장식 밀도를 줄여 한글 가독성을 확보한다.
- 스크롤을 가로채지 않고 기본 브라우저 탐색을 유지한다.
- 첫 화면과 일부 이야기 구간은 넓게 쓰되 미션과 문의는 빠르게 찾아갈 수 있게 한다.
- 검정·오프화이트·바이올렛을 기본으로 하고 따뜻한 노랑을 작은 강조에 사용한다.
- 현재 구현된 회의록 검토 미션의 원문 확인·오답 피드백·정답·프롬프트 복사·재시작 흐름을 유지한다.
- 기관명과 협업 내용은 사용자가 제공한 사실에 한정한다. 가상의 성과나 후기를 추가하지 않는다.
- 모바일에서는 입자 수와 효과를 줄인다. prefers-reduced-motion과 수동 일시정지를 지원한다.

## 현재 상태

사용자가 이미지 생성 단계 생략과 코드 직접 구현을 승인했다. `/ax-home/index.html`의 개편 구현과 시각 검증을 완료했다. 최종 설계는 `public/ax-home/design.md`, 검증은 프로젝트 루트 `design-qa.md`에 기록했다.
